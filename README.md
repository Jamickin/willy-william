# Willie William

Website for **Willie William**, a spa. The core feature is an online **booking system** so clients can view services and book appointments.

> Status: project setup. Waiting on brand assets, content, and requirements before choosing the tech stack and starting the build.

## Goals

- Show the spa's services, prices, and treatment details
- Let clients book appointments online (pick a service, staff member, date and time)
- Send booking confirmations and reminders
- Give staff a simple way to manage availability and bookings
- Look good and work well on phones
